## 位置与分层（最高频违例区）

- 计划稿放 `.zcode/plans/`；裁决稿/设计稿/纲领稿禁入 plans/，落 `.zcode/design/`（契约 §11）。
- 一切开发流程资产在 `.zcode/`（计划稿/板/证据/hook 配置）；技能资产在技能仓（`~/.zcode/skills/zcode-board/`）。
- `AGENTS.md` 只放团队表：看板/实验功能内容零残留。

## 写入者分域（文件级单写者）

- `runs.json` 只由 record-run 写；`interviews.json` 只由 register-interview 写；`registry.json` 只由 `--assign` 写；`board.json`/`board.md` 只由编译器写。
- 子智能体对板文件只读、**不写任何板文件**；报告必须带 `run_event` 块；merge 事实经 integrator 报告落账。

## 身份与引用

- 引用一律稳定号（`9`/`#9`/`ID-9` 等价归一）；层级标签（`1.2`）只是排版，拒入引用位；号永不复用、registry 高水位只增。

## 保护清单（动笔前核对）

- `design.md`/`tasks.md`：编排者维护，子智能体只读。
- 契约包（`assets/{board.schema.json,templates/,contracts/}`）：冻结，任何改动走新任务 + 版本号。
- 真实 plan 样例与真实板：只读；夹具/突变/篡改验证一律用副本域（真实板零污染）。

## 派发形态

- 后台方式派发；一卡一交付；特性拆卡首卡 = tracer（走通最薄能跑主干，其余卡 `blocked-by` 它；小改动豁免须在计划稿声明理由）。
- **拆粒度不砍范围**（2026-10-10，裁决③）：拆卡前先枚举用户意图的全量交付面（含提示词/hook/技能/文档/分发等配套件），完整范围 → 按文件域与可验证中间产物拆卡 → 并行派发同批收口；砍范围必须用户明示裁决，不得以"卡太大"为由（E1 V16）。
- **证据路径一律绝对路径**并原样使用（相对路径会写出幻影板/错位证据）；产出证据（红绿/命令输出）落 `.zcode/board/evidence/<任务>/`。
- 预估 >30 分钟的卡必须再拆；>60 分钟禁止整卡派发（SKILL.md §6.11）。

## 规格纪律（2026-10-10 用户批准）

- 用户反馈的关键句**原文引用**进卡（访谈 id + 原话引号原文），只给摘述/转译不算；验收句以"**用户看到/点到什么**"措辞；转译比原话窄是 plan-reviewer 的 finding（E1 V14/V15）。
- 卡文两必填段：**交付面全量枚举 + 用户原话引用**（形态见 `card.template.md`；缺段拒发归 #120/B6-2 校验面）。

## UI 卡门禁

- 改动面含布局/交互的 UI 卡：test-verifier 必跑浏览器断言（溢出探针 `scrollWidth > clientWidth`、点击路由派发后断言 DOM）；SSR 结构断言不构成行为证据。
- UI 卡第四绿：code-reviewer 之后强制 `ui-designer` 视觉/信息层级复核；无证据不得进待合并。
- 第四绿与浏览器断言**不随验证等级（`--level` 跟进/微卡）消减**（#121/B6-3；清单生成见下节）。

## 按卡类型需齐绿清单（#121/B6-3，2026-10-11 增；与等级三层配套）

- 拼装器按卡文**启发式判定卡类型**（ui → hook → 断言 → 纯 md 文档 → 默认代码卡），判定依据随拼装日志显式输出、不猜死；`--type` 可显式覆盖（仍输出启发式原判）。
- **需齐绿清单按类型生成**（随派发 prompt「角色与绿数」节留痕，可核对）：
  - UI 卡 = 三绿 + **第四绿**（ui-designer 视觉/信息层级复核）+ **浏览器断言**（溢出探针 `scrollWidth > clientWidth`、点击路由派发后断言 DOM）；
  - 断言卡 = 突变/反例证据（E4-24）；hook 卡 = run-t13 场景全绿 + 信任评审注记；文档卡 = 纯 md 注记（无附加专项）；代码卡 = 等级绿。
- 等级定绿数（SKILL.md §6.5 验证三层）：正式卡 = 完整三绿；跟进卡 = 第一绿 + 回归全绿 + 批量验证；微卡 = 第一绿 + 回归全绿——**UI 专项项不随等级消减**（上节）。

## 检查点纪律（绿了才走下一步）

- 新项目首次上板（`--preflight`）→ 新环境部署技能（`--doctor`）→ hook 安装启用（preflight + 信任评审）；三件事各有一个强制检查点。
- 断言/hook 类卡必须带突变或反例断言（E4-24）；证据脚本头写运行命令（可复现）。
