# 05: 浏览被投射设备文件系统添加项目

**What to build:** 在设备概览点「添加项目」，浏览**被投射设备（B）的文件系统**选择目录，把它登记到 B 的项目列表 —— 归属与数据都在 B，B 本机随后也能看到这个项目。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 可浏览被投射设备的目录树（不是本机目录）
- [ ] 选中目录后登记到被投射设备的项目列表
- [ ] 登记后该项目出现在设备概览与设置页的勾选候选里
- [ ] 只登记既有目录，不创建目录
- [ ] 写入前需用户确认（这是对另一端数据的修改）
- [ ] 验证：被投射设备的项目清单确实增加，且原始清单可在测试后恢复
