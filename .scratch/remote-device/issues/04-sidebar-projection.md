# 04: 侧边栏投射与项目勾选

**What to build:** 投射端侧边栏显示被投射设备（B）的项目，按用户在设置里的勾选决定显示哪些，带来源标记以区别于本机项目。断开连接后这些条目灰显并标注已断开，点击即重连。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 侧边栏在已连接时显示被勾选的项目，与本机项目混在同一列表
- [ ] 投射项目有明确的来源标记（图标/颜色），用户能区分本机项目与被投射设备项目
- [ ] 设置页可勾选显示哪些项目；候选项 = 被投射设备的项目清单（含新登记但尚无会话的）
- [ ] 勾选只影响投射端显示，**不修改被投射设备的项目列表**
- [ ] 断开连接后，投射项目条目灰显并标注已断开，点击即重连
- [ ] 断开后不缓存项目清单（项目清单连接后重新获取）
- [ ] 显示偏好保存在投射端（属于连接入口的一部分）
