# 04: 侧边栏投射与项目勾选

**What to build:** 投射端侧边栏显示被投射设备（B）的项目，按用户在设置里的勾选决定显示哪些，带来源标记以区别于本机项目。断开连接后这些条目灰显并标注已断开，点击即重连。

**Blocked by:** 02

**Status:** done（数据面+视觉均已跨机实测：10 项蓝色图标投射、勾选双向生效、断开清理）

- [x] 侧边栏在已连接时显示被勾选的项目，与本机项目混在同一列表（连接后 syncProjection 创建投射条目）
- [x] 投射项目有明确的来源标记 —— MonitorSmartphone 图标 + sky 配色，与本机 Folder/常规远程 Cloud 区分
- [x] 设置页可勾选显示哪些项目；候选项来自设备访问层的投影清单（并集，含新登记无会话的）
- [x] 勾选只影响投射端显示（偏好存在设备条目的 visibleProjects，不写对端）

- [x] 断开后不缓存项目清单 —— 投射条目是 tab 内存态（projection 字段），断开后 10→0；remote-devices.json 不含项目清单

**偏离原验收项一处**：原计划"断开后灰显保留并可点击重连"，实现改为"断开即移除投射条目，重连入口留在设置页"。理由见 ADR 0001 与被否决方案权衡：投射条目是内存态，保留灰显条目需要缓存项目清单，违背「断开后不缓存项目清单」的既有决定。设备条目本身仍在设置页保留，重连路径不变。
