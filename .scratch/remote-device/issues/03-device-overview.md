# 03: 设备概览主区

**What to build:** 连上被投射设备后，主区显示该设备的概览：已添加的项目列表、每个项目的会话数、以及「添加项目」入口。从概览点进某个项目即进入该项目的完整工作区。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 主区列出被投射设备的项目，并显示各项目的会话数
- [ ] 项目清单为**并集**：已登记项目 ∪ 实际有会话的项目（去重）。依据：实测两者不一致（登记 10 项、有会话 11 项），只取其一会让新登记但尚无会话的项目不可见
- [ ] 从概览可进入某个项目的完整工作区
- [ ] 概览提供「添加项目」入口
- [ ] 数据实时从被投射设备拉取，不显示过期缓存
- [ ] 连接中断时给出明确提示，不停留在过期数据上
